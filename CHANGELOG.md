# Changelog

Все заметные изменения проекта. Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [0.28.0] — 2026-10-14

### Добавлено
- **Генерация скрипта обучения из мастера (этап 31)** — `train_script.py`: мастер «Своя ЛЛМ» теперь не только считает план, но и пишет готовый `train_llm.py`:
  - путь «с нуля» — самодостаточный PyTorch-цикл (архитектура пресета, clip-градиентов, cosine-подготовка, чекпоинты);
  - LoRA/рецепты — Hugging Face Trainer + PEFT (r=16, alpha=32), базовая модель из настроек.
  - Скрипт печатает метрики и сэмплы в форматах приложения (`loss=…`, `epoch X/Y`, `eval: val_loss=…`, `{"sample": …}`), поэтому дашборды, «Сэмплы генерации» и «до/после» работают сразу.
  - Кнопка «Создать скрипт обучения» в мастере: сохраняет скрипт в рабочую папку, прописывает команду `python train_llm.py`, показывает, что исправить перед запуском (датасет/базовая модель).

## [0.27.0] — 2026-10-14

### Добавлено
- **Агент уровня лучших (этап 30)** — по итогам сравнения с Claude Code / Codex / Cursor Agent:
  - **LoopGuard**: защита от зацикливания — повтор одного вызова с тем же исходом 3 раза останавливает агента с честным отчётом (событие `loop_detected`, видно в чате).
  - **Retry с backoff**: транзиентные сбои провайдера (timeout/429/5xx/сеть) повторяются до 3 раз, фатальные (401/403) — нет; событие `retry` в логе чата.
  - **Классификация ошибок** `classify_error`: transient/permission/not_found/validation/fatal.
  - **Recovery-hint**: после 2 ошибок инструментов подряд агент получает системную подсказку сменить подход.
  - **TurnStats**: измеримая статистика каждого хода (шаги, вызовы, ошибки, ретраи, токены, время) в событии finished.
  - **`agent_bench.py`**: внутренний бенчмарк цикла агента (SWE-bench-идея, офлайн): 5 сценариев на реальном WorkspaceTools — починка файла, поиск бага, создание файла, readonly-гарантии, loop-guard; кнопка «Бенчмарк агента» на странице «Модель», отчёт вида «5/5 сценариев».

## [0.22.0] — 2026-10-14

### Added
- Plugin sandbox: plugins without `PLUGIN["trusted"] = True` are inspected
  and executed in a restricted worker subprocess — import whitelist, no
  `open`/`os`/`subprocess`/`socket`, wall-clock timeout and POSIX memory
  cap. A hung or malicious plugin can no longer freeze or compromise the
  app. Trust is detected statically (AST); user trust decisions persist in
  `plugins_trust.json`.
- Plugin catalog: curated installable plugins (`file:` and `https://`
  sources, optional SHA-256 integrity check) with install/uninstall from
  the Settings page; a bundled hello example installs offline.
- Settings → plugins: per-plugin trust display (trusted/sandboxed), trust
  toggle, catalog install and uninstall buttons.

## [0.12.0] — 2026-10-13

### Добавлено
- **Линтер Python** без внешних зависимостей: синтаксические ошибки (через `compile`) и стилевые предупреждения (лишние пробелы, табуляция в отступе, строки дольше 100 символов) — кнопка «Проверить» и автоматика при сохранении; результаты появляются в панели «Проблемы» и маркерах гуттера.
- **Встроенный форматтер**: нормализация переводов строк (CRLF→LF), удаление лишних пробелов в конце строк, сокращение пустых строк до двух, единый перевод строки в конце файла; кнопка «Формат» и опция «формат при сохранении»; каждое исправление подсчитывается.
- **Мини-карта редактора** справа от кода: уменьшенное представление файла с цветными полосами (функции/классы, ключевые слова, комментарии, код); клик по мини-карте переходит к нужной строке.
- **Масштаб шрифта** в редакторе: Ctrl++ / Ctrl+- (и Ctrl+колёсико-клавиши на цифровом блоке).

## [0.11.0] — 2026-10-13

### Добавлено
- **Панель «ГИТ»** (Ctrl+Shift+G) во вкладках нижней панели: список изменённых файлов со статусом и +/-, предпросмотр различий с подсветкой, действия «Индексировать / Снять из индекса / Отменить изменения», коммит с сообщением, Push / Pull (fast-forward), открытие файла двойным кликом.
- **Автозакрытие скобок и кавычек** в редакторе: парные символы вставляются вместе, повторный ввод закрывающей скобки перешагивает её, Backspace между пустой парой удаляет обе; подсветка парной скобки при курсоре.
- **Переход к строке** (Ctrl+G) с номером строки в панели редактора.
- **Операции с файлами** в дереве редактора: создать файл (в том числе во вложенных папках), переименовать, удалить; имена проверяются на выход за пределы рабочей папки.

## [0.10.0] — 2026-10-13

### Добавлено

## [0.7.0] — 2026-10-13

### Добавлено
- **Диагностика** («Доктор»): проверка Python, Tk, системного хранилища ключей, paramiko, Git, рабочей папки, свободного места и настроек наставника; отчёт можно скопировать; инструмент `run_diagnostics` у агента.

- **Журнал ошибок**: `<app data>/logs/hub.log` (ротация), перехват необработанных исключений с показом пути к логу.

### Усилено (безопасность)
- SSH: проверка host-ключей (system known_hosts + app-файл, TOFU-pinning вместо слепого принятия) с отчётом `SHA256:…` и отказом при подмене ключа.
- SSH: ограничено чтение вывода команд (защита от переполнения памяти).
- Ошибки фоновых задач и колбэков пишутся в лог с трассировкой.
