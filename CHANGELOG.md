# Changelog

Все заметные изменения проекта. Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [0.18.0] — 2026-10-13

### Добавлено
- **Очередь облачных заданий (RunPod/Colab-совместимый flow)**: задания обучения (название, команда, образ, GPU) в очереди `cloud_jobs.json` → отправка в RunPod одной кнопкой (с подтверждением оплаты) → отслеживание pod (статусы pending/queued/submitted/running/done/failed/cancelled). Карточка «Очередь облачных заданий» на странице GPU; инструменты агента `list_cloud_jobs` и `submit_cloud_job`.
- **Экспорт полного отчёта**: модель, метрики с трендами, валидация (переобучение/лучшая эпоха), watchdog, план агента, оценка наставника и журнал действий → Markdown или печатный HTML (PDF через Ctrl+P в браузере). Кнопка «Экспорт отчёта» на дашборде, инструмент `export_report`.
- **Шаринг сессий**: выгрузка диалога с агентом в Markdown/HTML/JSON и обратный импорт JSON — кнопки «Выгрузить»/«Импорт» в чате.
- **Роли и гостевой доступ**: владелец / редактор / гость — гостевой режим делает агента и все инструменты строго только для чтения (мутации отклоняются). Роль выбирается в настройках.

## [0.17.0] — 2026-10-13

### Добавлено
- **Экспорт моделей в ONNX/GGUF**: точные команды конвертации (transformers.onnx / llama.cpp), проверка артефакта (размер, GGUF-магия) и понятные подсказки, если конвертеры не установлены. Кнопка «Экспорт» на странице «Модели», инструмент агента `export_model`.
- **Квантизация**: рецепты Q8_0/Q5_K_M/Q4_K_M/Q4_0/Q3_K_M (GGUF) и INT8 (ONNX) с расчётом размера (×3–×4 экономии), оценкой потери качества и проверкой результата; инструмент `quantize_model`.
- **Бенчмарки моделей**: замер мс/запуск и tok/s несколькими прогонами (с прогревом), хранение результатов в benchmarks.json, рейтинг «по скорости / по токенам»; кнопка «Бенчмарк», инструмент `benchmark_model`.
- **Пакетное тестирование промптов**: набор из 5 промптов (с ожиданиями) → ответы модели, задержки, вердикты, отчёт; свой JSON-набор поддерживается; кнопка «Промпт-набор» в Playground и на странице «Модели», инструмент `run_prompt_suite`.

## [0.16.0] — 2026-10-13

### Добавлено
- **Hugging Face Datasets**: загрузка строк датасета (`datasets-server.huggingface.co`, с подтверждением и лимитами), добавление в библиотеку одной кнопкой.
- **Фильтр и разбиение датасетов**: `filter_rows` (подстрока/длина) + детерминированное `split_rows` на train/val/test — из интерфейса и через инструмент агента `prepare_dataset` (с дифф-подтверждением).
- **Eval-конвейер**: шаблонный `train.py` валидируется каждую эпоху (val_loss/val_acc/perplexity); модуль `evaluation.py` — perplexity, лучшая эпоха, детекция **переобучения**, вердикт; инструмент агента `get_eval_report`.
- **A/B-сравнение запусков**: кнопка «Сравнить два последних запуска» на странице обучения — наложение графиков loss и вердикт «победитель»; инструмент агента `compare_runs`.
- **Авто-подбор гиперпараметров**: `hparam_tuning.suggest_fixes` — предложения lr/grad_clip/early_stop_patience по сигналам watchdog; кнопка «Подобрать параметры» с применением в `control.json`; инструмент агента `suggest_training_fixes`.

## [0.15.0] — 2026-10-13

### Добавлено
- **Дифф-предпросмотр агента**: каждое изменение файла (write_file/replace_in_file) показывается unified-диффом прямо в диалоге подтверждения; новый инструмент `diff_files` для самопроверки сравнением файлов.
- **Живой график метрик**: страница «Модель и прогресс» обновляется каждые 5 секунд во время работы, сетка и деления по шкале, легенда с последними значениями.
- **План агента с прогрессом**: инструмент `update_plan` со статусами шагов (pending/in_progress/done/failed) — чек-лист отображается в чате.
- **Watchdog обучения** (фоновый контроль): детекторы всплеска loss, роста loss, плато, NaN/Inf и зависания процесса — предупреждения с подсказками (в т.ч. через set_training_control) в журнале и под графиком.
- **Профили агента**: Наставник / Ревьюер кода / Оптимизатор обучения / Полный агент — быстрые пресеты шагов, рассуждений, самопроверки, подагентов и системного промпта.

## [0.14.0] — 2026-10-13

### Добавлено
- **Мульти-провайдеры ИИ**: OpenAI (GPT), OpenAI Codex, Anthropic (Claude), Google (Gemini), OpenRouter, Ollama (локально), DeepSeek, Groq, Mistral, свой сервер — единый слой `llm_providers` с родными протоколами (включая function calling для Claude и Gemini). Выбор провайдера в настройках подставляет URL и подсказки моделей.
- **Агент видит всю информацию о ЛЛМ и обучении**: `get_model_info` (каталог, конфиг проекта, метрики, аномалии, состояние обучения), `list_model_catalog`, `get_metrics_history` (серии loss/acc по эпохам).
- **Корректировка обучения на лету**: `set_training_control` — learning rate, предел эпох, ранняя остановка, ограничение градиентов, остановка (stop) через `control.json`; шаблонный `train.py` применяет изменения со следующей эпохи и сбрасывает флаг остановки. Панель «Проблемы»/метрики видят результат сразу.
- **Точный сильный агент**: протокол «план → действие → проверка» (`set_plan`), обязательная **самопроверка** результата read-only проходом с вердиктом PASSED/FAILED, сжатие контекста для длинных сессий, режим «только чтение» для проверок, **подагенты** (`spawn_subagent`) для узких подзадач.
- **Настройка агента** (Настройки → «ИИ-агент»): максимум шагов, уровень рассуждений (off/low/medium/high для OpenAI/Codex), самопроверка, подагенты, дополнительные инструкции (системный промпт).

## [0.13.0] — 2026-10-13

### Добавлено
- **Тёмная тема** наряду со светлой: переключение в настройках («Внешний вид») или через палитру команд применяется сразу ко всему интерфейсу и сохраняется при перезапуске; макет `docs/ui-dark.png`.
- **Разделённый вид редактора** (Ctrl+\\ или кнопка «Разделить»): две синхронизированные панели одного файла, правка в любой из них, общий гуттер с маркерами.
- **CI (GitHub Actions)**: ruff + compileall + pytest на Python 3.11/3.12 при каждом push и pull request, сборка wheel/sdist с выкладкой артефактов; окно `.exe` по-прежнему собирает workflow «Windows Desktop Build».
- **Кросс-платформенный скрипт сборки** `scripts/build_desktop.py` (PyInstaller) — тот же конвейер, что и для Windows, на Linux/macOS.

## [0.12.0] — 2026-10-13

### Добавлено
- **Линтер Python** без внешних зависимостей: синтаксические ошибки (через `compile`) и стилевые предупреждения (лишние пробелы, табуляция в отступе, строки дольше 100 символов) — кнопка «Проверить» и автоматика при сохранении; результаты появляются в панели «Проблемы» и маркерах гуттера.
- **Встроенный форматтер**: нормализация переводов строк (CRLF→LF), удаление лишних пробелов в конце строк, сокращение пустых строк до двух, единый перевод строки в конце файла; кнопка «Формат» и опция «формат при сохранении»; каждое исправление подсчитывается.
- **Мини-карта редактора** справа от кода: уменьшенное представление файла с цветными полосами (функции/классы, ключевые слова, комментарии, код); клик по мини-карте переходит к нужной строке.
- **Масштаб шрифта** в редакторе: Ctrl++ / Ctrl+- (и Ctrl+колёсико-клавиши на цифровом блоке).

## [0.11.0] — 2026-10-13
