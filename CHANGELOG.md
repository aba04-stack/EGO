# Changelog

Все заметные изменения проекта. Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [0.7.0] — 2026-10-13

### Добавлено
- **Диагностика** («Доктор»): проверка Python, Tk, системного хранилища ключей, paramiko, Git, рабочей папки, свободного места и настроек наставника; отчёт можно скопировать; инструмент `run_diagnostics` у агента.
- **Горячие клавиши**: Ctrl+1…Ctrl+9 — страницы, Ctrl+0 — настройки, Ctrl+K — чат, Ctrl+J — терминал, F5 — обновить, F1 — справка.
- **Журнал ошибок**: `<app data>/logs/hub.log` (ротация), перехват необработанных исключений с показом пути к логу.

### Усилено (безопасность)
- SSH: проверка host-ключей (system known_hosts + app-файл, TOFU-pinning вместо слепого принятия) с отчётом `SHA256:…` и отказом при подмене ключа.
- SSH: ограничено чтение вывода команд (защита от переполнения памяти).
- Ошибки фоновых задач и колбэков пишутся в лог с трассировкой.

## [0.6.0] — 2026-10-13

### Добавлено
- **Серверы (SSH)**: реестр, вход по ключу/паролю (пароли — в keyring), проверка связи, информация о системе, команды вручную, из терминала и агентом (`list_servers`, `server_info`, `run_on_server`).
- Терминал: цель «Локально / сервер», сворачивание панели.
- Сворачиваемые секции настроек (▼/▶) на всех страницах.

## [0.5.0] — 2026-10-13

### Добавлено
- **IDE-раскладка**: сайдбар, центр (страницы), терминал снизу, докнутый чат справа.
- **Агент-наставник**: режимы «Ассистент»/«Режим агента», цель-ориентированный цикл `run_goal`, запуск/остановка обучения инструментами.
- **Коннекторы**: GitHub, Hugging Face, Gmail (SMTP); секреты — в keyring; инструменты агента.

## [0.4.0] — 2026-10-12

### Добавлено
- **LLM Studio**: редактор кода с деревом файлов и шаблонами проектов (`train.py`/`eval.py`/`config.json`).

- Сгруппированная навигация (РАЗРАБОТКА / БИБЛИОТЕКА / ЭКСПЕРИМЕНТЫ / СИСТЕМА).
