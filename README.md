# EGO

EGO — экспериментальная настольная программа для работы с языковыми моделями: редактор кода и терминал, ИИ-наставник, каталог моделей и датасетов, метрики обучения и инструменты для локальных/облачных вычислений.

> **Личный эксперимент для интереса и обучения.** Автор не профессиональный разработчик. Программа может содержать ошибки или не запуститься; работа, безопасность и поддержка не гарантируются. Используйте на свой риск.

## Скачать

**[Открыть загрузки последней версии →](https://github.com/aba04-stack/EGO/releases/latest)**

В разделе **Assets** выберите нужный файл:

- **Windows x64:** `EGO-Windows-x64.zip` — распакуйте архив и запустите `EGO.exe`. Python не нужен.
- **Windows с Python:** `ego_desktop-*.whl` и `install-windows.bat` из одного релиза.
- **Linux / macOS:** тот же `ego_desktop-*.whl` и `install-linux-mac.sh` из одного релиза.
- **Исходный код:** `ego_desktop-*.tar.gz` или код репозитория.

Для установки через Python рекомендуется Python 3.11 или 3.12. Инструкции: [УСТАНОВКА.md](release-download/УСТАНОВКА.md). Файлы установщика и wheel должны быть скачаны **из одного и того же релиза**.
