# AlterEgo Training Hub Desktop

A desktop control panel for managing AI-model training projects from a laptop. Connect a local or remote Git repository, configure an API mentor, inspect cloud GPU availability and prices, and manage experiments without exposing API keys in the repository.

## Status

Initial project bootstrap. The app is being built as a Python desktop application, with Windows packaging planned via PyInstaller after the MVP is tested. End-to-end remote training, dataset transfer, and automated budget shutdown are not yet claimed as complete.
