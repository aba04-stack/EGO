## План развития (качественный, после v0.23.0)

### Этап 26 — Прозрачность ЛЛМ: что модель думает и что делает ✅ (v0.24.0)
Чтобы можно было ПРОВЕРЯТЬ модель, а не слепо ей верить.

| # | Задача | Зачем |
|---|--------|-------|
| 1 | **«Мысли агента» (Thought Stream)**: каждое сообщение агента раскрывается в цепочку «Мысль → Действие → Ответ»; для reasoning-моделей (DeepSeek-R1, o-series и т.п.) — показ сырого рассуждения; для обычных — структурированный протокол через промпт агента | Видно, ПОЧЕМУ агент ответил именно так |
| 2 | **Журнал действий (Action Trace)**: панель «Что агент сделал» — каждый вызов инструмента карточкой: инструмент, аргументы, результат, зачем (из плана), статус; кнопка «Объяснить» у каждого шага | Проверка: агент не «тихо» делает лишнего |
| 3 | **Панель «Контекст»**: что модель реально видит — system-промпт, последние сообщения, суммарный счётчик токенов и оценка стоимости запроса | Никакой магии: прозрачность промпта |
| 4 | **Самопроверка ответов (self-critique)**: режим «Критик» — второй проход «сверь ответ с файлами/метриками»; флаг «⚠ проверить» при противоречиях; оценка уверенности агента в ответе | Ловит галлюцинации ДО того, как им поверят |
| 5 | **«Что модель генерирует» при обучении**: сэмплы генерации на валидации каждые N шагов, топ-k предсказаний следующего токена, перплексия по батчам; сравнение двух чекпоинтов одним промптом | Видно, ЧТО модель думает на самом деле, по ходу обучения |
| 6 | **Связка с ночным дежурством**: утренний итог ссылается на конкретные действия и мысли агента за ночь | Утро = разбор, а не пересказ |

Критерии готовности: у каждого сообщения агента есть раскрытие «почему»;
панель контекста показывает реальный промпт и токены; «Критик» работает по
кнопке у любого ответа; сэмплы генерации видны на странице «Модель».

### Этап 27 — Мастер «Своя ЛЛМ»: от идеи до обученной модели
Сделать обучение своей ЛЛМ по-настоящему удобным.

| # | Задача | Зачем |
|---|--------|-------|
| 1 | **Пошаговый мастер** (5 экранов, без ручного редактирования JSON): путь → данные → токенизатор/архитектура → ресурсы → обучение и оценка | Главный вход для новичка |
| 2 | **Выбор пути**: «дообучить готовую» (LoRA/QLoRA), «обучить с нуля» (свой токенизатор + конфиг архитектуры), «рецепты» (чат-бот на своих данных, код-ассистент, классификатор) | Понятная развилка вместо голых полей |
| 3 | **Аудит данных**: объём, дубликаты, язык, PII-риски, качество — чек-лист до старта с авто-проверками | Мусор в данных = мусорная модель |
| 4 | **Пресеты архитектур** (GPT-2 small/medium, Llama-like, «своя» с валидацией) + **калькулятор ресурсов**: параметры → память GPU → часы → цена (в связке с RunPod) ДО старта | Без сюрпризов в счёте |
| 5 | **Рекомендации агента**: lr/batch/warmup по калькулятору и аудиту данных; ранняя остановка; расширение watchdog до «health check» обучения | Агент-наставник подсказывает, а не только констатирует |
| 6 | **Оценка качества**: perplexity, прогон своих промптов, сравнение «до/после» и с базовой моделью; экспорт в GGUF/ONNX (уже есть) | Доказательство, что модель стала лучше |

Критерии готовности: путь «свои данные → обученная модель» проходится
мастером за один заход; калькулятор показывает цену до старта; сравнение
«до/после» — одной кнопкой.

### Этап 28 — UX: кнопки и раскладка «как у лучших IDE»
Бенчмарк: VS Code / Cursor (activity bar, палитра, статус-бар), LM Studio /
Jan (модели и чат), ChatGPT desktop (ввод и иконки у поля).

| # | Что у других | Что сделаем у нас |
|---|--------------|-------------------|
| 1 | Узкий иконочный **activity bar** слева (VS Code/Cursor) | Сайдбар-группы сворачиваются в иконки с бейджами (ошибки, фоновые задачи), раскрытие по клику/наведению; док влево/вправо сохраняется |
| 2 | **Primary-действие справа в шапке страницы** (Cursor, Linear) | Единый паттерн: главное действие — справа в заголовке («Новая тренировка», «Запустить», «Отправить задание»), вторичные — в меню «…»; сейчас кнопки разбросаны по страницам по-разному |
| 3 | Иконки у поля ввода чата (ChatGPT desktop) | У поля ввода: 🎤 диктовка, 📎 вложение, 🔧 инструменты, переключатель «Агент / Вопрос»; верхний ряд чата свернуть до «Новый» + «…» («Выгрузить/Импорт/Метрики» → в меню) |
| 4 | История чатов — списком сбоку (ChatGPT, Cursor) | Сессии — компактный список с поиском вместо выпадающего списка |
| 5 | Насыщенный **статус-бар** (VS Code) | В статус-бар: текущая модель/провайдер, токены/бюджет дня, состояние обучения (клик → переход на страницу) |
| 6 | **Палитра команд на всё** (Ctrl+K) | Каждая кнопка приложения — команда палитры с хоткеем; тултипы с хоткеями на всех иконочных кнопках |
| 7 | Сетка 8px, единые стили, красное только для деструктивного | Довести до единой сетки и токенов отступов; подтверждения для деструктивных действий |

Критерии готовности: ни одно главное действие не «теряется»; у каждой
кнопки — хоткей или палитра команд; скорость ввода в чате не хуже, чем
в Cursor; раскладка проверена на 1366×768.

## Принципы

- Каждый инструмент агента — либо точно читает, либо подтверждается и обратим (бэкапы).
- Никаких сетевых зависимостей в ядре: провайдеры подключаются модулями.
- Все чистые логики (chart, watchdog, diff, профили) тестируются без tkinter.
- Русский интерфейс и общение; продукт — среда разработки ЛЛМ-моделей.
