# Зачем нужен EGO

EGO — настольная студия **для обучения языковых моделей (LLM)**.

Не чат-бот «для дома» и не набор разрозненных утилит. Смысл программы —
пройти путь **свои данные → обучение → метрики → чекпоинт**, не собирая
стек вручную из скриптов Hugging Face / TRL.

## Что делает

1. **Данные** — датасеты, аудит, шаблоны чата, сплит train/val.
2. **Обучение** — SFT / LoRA (и обучение с нуля в мастере), живой лог и
   график loss, watchdog (NaN, плато, рост лосса).
3. **Оценка** — val_loss, сэмплы генерации, сравнение запусков.
4. **Модель** — каталог, чекпоинты, квантизация/экспорт.
5. **Наставник** — разбор лога и кода рядом с обучением (не вместо него).
6. **Железо** — локальный запуск или внешние GPU, когда своей карты мало.

## Чем это не является

- Не «домашний помощник» и не замена ChatGPT.
- Не облачный SaaS: приложение ставится на машину, где идёт обучение.
- Экспериментальный проект: без гарантий; см. дисклеймер в README.
