# EGO — установка на ПК

## Какой файл скачивать

Для актуальной версии откройте **Releases** репозитория и скачайте нужные активы одного и того же релиза:
- **Windows без Python:** `EGO-Windows-x64.zip`; распакуйте и запустите `EGO.exe`.
- **Установка через Python:** wheel-файл `ego_desktop-<версия>-py3-none-any.whl`.
- **Исходный архив:** `ego_desktop-<версия>.tar.gz`.

Старые артефакты версии 1.15.0 удалены из каталога `release-download`. Для установки используйте только активы одного актуального GitHub Release.

## Что нужно для установки wheel

Python 3.11 или 3.12; при установке Windows включите «Add python.exe to PATH». Tkinter обычно входит в установщик Python для Windows/macOS. На Debian/Ubuntu установите его системным пакетом: `sudo apt install python3-tk`. Интернет нужен для установки зависимостей.

## Windows

1. Скачайте wheel и `install-windows.bat` из одного и того же GitHub Release и положите их в одну папку.
2. Запустите `install-windows.bat`. Он проверит, что найден ровно один wheel, установит приложение и `cryptography`.
3. Запуск: `ego` или `run-ego.bat`.

При переходе со старого пакета один раз удалите его (`py -m pip uninstall alterego-training-hub-desktop`), затем установите новый wheel: `py -m pip install "имя-скачанного-wheel.whl" cryptography`.

## Linux/macOS

1. Скачайте wheel и `install-linux-mac.sh` из одного и того же GitHub Release в одну папку.
2. Выполните `chmod +x install-linux-mac.sh`, затем `./install-linux-mac.sh`.
3. Запуск: `ego`.

В управляемой системной среде Python создайте виртуальное окружение и выполните установку внутри него.

## Удаление

Windows: `py -m pip uninstall ego-desktop`. Linux/macOS: `python3 -m pip uninstall ego-desktop`.

## Честно о границах

Для обучения моделей дополнительно понадобятся `torch`, `transformers` и `peft`; приложение подскажет команды при первом запуске обучения. CI-проверка и релизная сборка не заменяют проверку установки на чистом целевом компьютере.
