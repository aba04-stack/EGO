# AlterEgo LLM Studio 1.15.0 — установка на ПК

Готового .exe в этом пакете нет: исполняемый файл собирается на Windows-машине
(PyInstaller не умеет собирать Windows-.exe из Linux). Установка ниже работает
на Windows, Linux и macOS и занимает пару минут.

## Что нужно
- Python 3.11 или 3.12 (python.org; при установке на Windows отметить
  галочку «Add python.exe to PATH»). Tkinter входит в стандартный установщик
  Python для Windows/macOS. На Linux: `sudo apt install python3-tk`.
- Интернет на время установки (pip докачает зависимости).

## Установка (Windows)
1. Скачайте файл `alterego_training_hub_desktop-1.15.0-py3-none-any.whl`
   в папку, например `C:\AlterEgo\`.
2. Откройте командную строку (Win+R → `cmd`) и выполните:
   ```
   cd C:\AlterEgo
   py -m pip install --upgrade pip
   py -m pip install alterego_training_hub_desktop-1.15.0-py3-none-any.whl
   ```
   Для облачных/подписанных обновлений дополнительно:
   `py -m pip install "alterego-training-hub-desktop[package]"` —
   либо просто поставьте cryptography: `py -m pip install cryptography`.
3. Запуск:
   ```
   alterego-llm-studio
   ```
   Если команду не находит, запустите так: `py -m alterego_training_hub`
   (если модуль так не стартует — используйте команду выше после
   переустановки; путь Scripts должен быть в PATH).

## Установка (Linux/macOS)
```bash
python3 -m pip install alterego_training_hub_desktop-1.15.0-py3-none-any.whl
alterego-llm-studio
```

## Удаление
```
py -m pip uninstall alterego-training-hub-desktop
```

## Честно о границах
- Это та же версия 1.15.0, что прошла 519 тестов и чистую установку в
  изолированной среде (проверено на Linux). На Windows установка не
  проверялась — если что-то пойдёт не так, пришлите текст ошибки.
- Для обучения моделей дополнительно понадобятся torch/transformers/peft
  (приложение подскажет команды при первом запуске обучения).
